# CS4220-TVMaze

A Node.js Command Line Interface (CLI) application (cli.js) that interacts with the selected API and a JSON history file. 
The application's purpose is to allow a user to search and the get detailed information through the CLI, while storing search keywords in a history file. 
The application will transition to Express server-based and use MongoDB for database storage.
